Pipeline

From raw sequencing reads to resistance interpretation.

  • Assembly

    Use the raw sequencing reads to assemble the genome and get clean sequences from the data provided by Illumina or ONT platforms using SPAdes or Raven.

    Input: FASTQ

    Output: FASTA assembled genome

  • Annotation

    Use the assembled genome to get an annotation of the genome using Bakta.

    Input: FASTA assembled genome

    Output: Annotated genome

  • Prediction

    Use the annotated genome to get a prediction of antibiotic resistance.

    Input: Annotated genome

    Output: Model predictions and interpretation
