Annotate FASTA

Select a FASTA file to annotate its genomic features using Bakta and make them available for prediction.

What happens?

Bakta analyzes the genome sequence and identifies and annotates genes and other genomic features. The resulting annotations are then stored in Cocos so they can be used by prediction models.
